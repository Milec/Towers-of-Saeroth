# Emote single action  *Familiar Ability*

**Source** [[Sources/Rage of Elements]] pg. 42

**Ability Type** Specific Familiar - Mood Cloud

The cloud of sentiment changes the expression on its miniature face. It prepares to [[Actions/Aid]] you on a skill check for a skill matching its expression: [[Rules/Skills/Deception]] for an inscrutable expression, [[Rules/Sidebars/Changing Attitudes|Diplomacy]] for a friendly expression, or [[Rules/Skills/Intimidation]] for an angry expression. It gains a reaction this round, which it can use only to Aid you in this way. It automatically succeeds at its check to Aid you with the skill or automatically critically succeeds if you're a master of the skill in question.
