# Invisibility two actions  *Spell 2*

**Traits** [[Traits/Illusion]], [[Traits/Manipulate]], [[Traits/Subtle]]

**Source** [[Sources/Player Core]] pg. 339

**Traditions**
[[Magic/Traditions/Arcane]], [[Magic/Traditions/Arcane|Occult]]

**Deities**
[[Setting/Deities/Achaekek (Divine Mysteries)|Achaekek]], [[Setting/Deities/Erecura (Divine Mysteries)|Erecura]], [[Setting/Deities/Fortune's Fate]], [[Setting/Deities/Ketephys (Divine Mysteries)|Ketephys]], [[Setting/Deities/Nalinivati (Divine Mysteries Web Supplement)|Nalinivati]], [[Setting/Deities/Ng (Divine Mysteries)|Ng]], [[Setting/Deities/Nivi Rhombodazzle (Divine Mysteries)|Nivi Rhombodazzle]], [[Setting/Deities/Norgorber (Divine Mysteries)|Norgorber]], [[Setting/Deities/Raumya (Divine Mysteries)|Raumya]], [[Setting/Deities/Shax (Divine Mysteries)|Shax]], [[Setting/Deities/The Tides of Chaos]], [[Setting/Deities/Yaezhing (Divine Mysteries Web Supplement)|Yaezhing]], [[Setting/Deities/Zugero]]

**Range** touch

**Target** 1 creature

**Duration** 10 minutes

---

Illusions bend light around the target, rendering it [[Rules/Conditions/Invisible|invisible]]. This makes it [[Rules/Conditions/Undetected|undetected]] to all creatures, though the creatures can attempt to find the target, making it [[Rules/Conditions/Hidden|hidden]] to them instead. If the target uses a [[Rules/Hostile Actions|hostile action]], the spell ends after that hostile action is completed.

---
**Heightened (4th)** The spell lasts 1 minute, but it doesn't end if the target uses a hostile action.
