# Imprint Message two actions  *Spell 1*

**Traits** [[Traits/Divination]]

**Source** [[Sources/Advanced Player's Guide]] pg. 221

**Tradition**
[[Magic/Traditions/Arcane|Occult]]

**Cast** [[Rules/Somatic|somatic]], [[Rules/Verbal|verbal]]

**Range** touch

**Target** 1 object

---

You project psychic vibrations onto the target object, imprinting it with a short message or emotional theme of your design. This imprinted sensation is revealed to a creature who casts [_object reading_](https://2e.aonprd.com/Spells.aspx?ID=553) on the target object, replacing any emotional events the item was present for. If the object is in the area of a [[Spells/Retrocognition|_retrocognition_]] spell, the imprinted messages appear as major events in the timeline, but they don't interfere with any other visions.

 If the object is targeted with [[Spells/Read Aura|_read aura_]] of a higher spell level than _imprint message_, the caster learns that the object has been magically modified. When you Cast this Spell, any prior vibrations placed on an object by previous castings of _imprint message_ fade.
