# Uncontrollable Dance two actions  *Spell 8*

**Traditions**
[[Magic/Traditions/Arcane]], [[Magic/Traditions/Arcane|Occult]]

**Bloodlines**
[[Classes/Subclasses/Bloodlines/Aberrant (Player Core 2)|Aberrant]], [[Classes/Subclasses/Bloodlines/Fey (Player Core 2)|Fey]]

**Deities**
[[Setting/Deities/Ashava (Divine Mysteries)|Ashava]], [[Setting/Deities/Hathor (Divine Mysteries Web Supplement)|Hathor]], [[Setting/Deities/Kofusachi (Divine Mysteries Web Supplement)|Kofusachi]], [[Setting/Deities/The Perplexing Jest]]

**Range** touch

**Target** 1 creature

**Defense**
Will

**Duration** varies

---

The target is overcome with an all-consuming urge to dance. For the duration of the spell, the target is [[Rules/Conditions/Off-Guard|off-guard]] and can't use reactions. It also can't use [[Traits/Move|move]] actions except to dance, using the Stride action to move up to half its Speed.

**Critical Success** The target is unaffected.  

**Success** The spell's duration is 3 rounds, and the target must spend at least 1 action each turn dancing.  

**Failure** The spell's duration is 1 minute, and the target must spend at least 2 actions each turn dancing.  

**Critical Failure** The spell's duration is 1 minute, and the target must spend all its actions each turn dancing.
