# Rust Scrub  *Item 1*

> [!warning] Spoilers
> May contain spoilers from Rusthenge

**Traits** [[Traits/Uncommon]], [[Traits/Alchemical]], [[Traits/Consumable]]

**Source** [[Sources/Rusthenge]] pg. 59

**Price** 2 gp

**Usage** held in 1 hand

**Bulk** L

---

This salt scrub is infused with citron juice and alchemical ingredients that allow it to fight rust on metallic equipment. One application can be used to restore 2d4 Hit Points to an item that has been damaged by rust. The GM determines what portion of damage to an item was caused by rust if that value isn't known.
