# Armor Latches  *Item 1*

**Traits** [[Traits/Adjustment]]

**Source** [[Sources/Treasure Vault]] pg. 11

**Price** 4 gp

**Usage** applied to armor

---

This armor is easily doffed. A set of armor with armor latches gains the [[Traits/Noisy (Player Core)|noisy]] trait; you can’t add latches to armor that already possesses the noisy trait. You can remove a set of armor with armor latches with a 3-action activity, which has the [[Traits/Manipulate (Player Core)|manipulate]] trait. This doesn’t affect the time it takes to don the armor.
