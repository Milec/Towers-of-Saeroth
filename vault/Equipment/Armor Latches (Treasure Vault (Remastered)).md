# Armor Latches  *Item 1*

**Traits** [[Traits/Adjustment]]

**Source** [[Sources/Treasure Vault (Remastered)]] pg. 11, [[Sources/The Mwangi Expanse]] pg. 258

**Price** 4 gp

**Usage** applied to armor

---

This armor is easily doffed. A set of armor with armor latches gains the [[Traits/Noisy|noisy]] trait; you can't add latches to armor that already possesses the noisy trait. You can remove a set of armor with armor latches with a 3-action activity, which has the [[Traits/Manipulate|manipulate]] trait. This doesn't affect the [[Rules/Donning and Removing Armor|time it takes to don the armor]].
