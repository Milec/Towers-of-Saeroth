# Energizing Treat  *Item 7*

**Traits** [[Traits/Consumable]], [[Traits/Magical]], [[Traits/Transmutation]]

**Source** [[Sources/Treasure Vault]] pg. 96

**Price** 70 gp

**Usage** held in 1 hand

**Activate**

single action

Interact

---

An _energizing treat_ is a treat made from meat or grains. When you feed your animal companion or familiar an energizing treat, it’s [[Rules/Conditions/Quickened (Player Core)|quickened]] for 1 minute. It can use the extra action each round only for [[Actions/Strike (Book of the Dead)|Strike]], [[Actions/Stride (Player Core)|Stride]], and [[Actions/Support (Player Core)|Support]] actions, and it can do so only if it normally has those actions available and you take the proper action to command it.
