# Tide of Death  *Relic Major Gift*

**Traits** [[Traits/Void]]

**Source** [[Sources/GM Core]] pg. 312

**Aspect** Death

**Prerequisite** death gaze gift

---

You can Activate death gaze with 3 actions instead of 2. If you do, it targets all living creatures within 30 feet except for you. If you have the [[Bestiary/Abilities/Negative Healing|void healing]] ability, you can include yourself to be healed.
