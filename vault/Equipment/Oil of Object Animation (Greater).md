# Oil of Object Animation  *Item 8+*

**Traits** [[Traits/Uncommon]], [[Traits/Consumable]], [[Traits/Magical]], [[Traits/Oil]], [[Traits/Transmutation]]

**Source** [[Sources/Advanced Player's Guide]] pg. 258

**Usage** held in 2 hands

**Activate**

two actions

Interact

---

This fine golden oil comes in a small blue canister. Carefully spreading the oil over an object turns it into an [[Bestiary/Families/Animated Object|animated object]] of the same type. For example, sprinkling it on a statue makes an [[Bestiary/Animated Statue|animated statue]]. If the animated object's level would be greater than 3, the oil struggles to animate it and ultimately fails.

 This animated object has the [[Traits/Minion|minion]] trait, meaning it can use 2 actions when you Command it. You can issue a Command for the current turn as part of the activation. The object remains animated for 1 minute before falling inert. As usual, you can have a maximum of four minions under your control.
