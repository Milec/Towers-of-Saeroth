# Alchemist's Toolkit  *Item 0*

**Source** [[Sources/Player Core]] pg. 287

**Price** 3 gp

**Hands** -1

**Bulk** 1

---

This mobile collection of vials and chemicals can be used for simple alchemical tasks. If you wear your alchemist's toolkit, you can draw and replace them as part of the action that uses them.

You can use a toolkit with 1 hand if you’re wearing it or 2 if you’re holding it. [[Rules/Wearing Toolkits|See here for details]].
