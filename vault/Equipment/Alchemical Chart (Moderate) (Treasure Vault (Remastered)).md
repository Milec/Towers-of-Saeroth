# Alchemical Chart  *Item 4+*

**Traits** [[Traits/Alchemical]]

**Source** [[Sources/Treasure Vault (Remastered)]] pg. 62

**Usage** held in 1 hand

**Bulk** L

---

This sturdy, rigid alchemical chart contains shorthand references on quickly mixing reagents for maximum effect. If you hold this chart while using [[Feats/Quick Alchemy]], the items you create of the listed level remain potent for 1 additional round.

## Alchemical Chart (Lesser)  *Item 4*

**Source** [[Sources/Treasure Vault (Remastered)]] pg. 62
