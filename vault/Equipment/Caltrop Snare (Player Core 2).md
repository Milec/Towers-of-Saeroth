# Caltrop Snare  *Item 1*

**Traits** [[Traits/Consumable (Player Core)|Consumable]], [[Traits/Mechanical (Player Core)|Mechanical]], [[Traits/Snare (Player Core 2)|Snare]], [[Traits/Trap (Player Core)|Trap]]

**Source** [[Sources/Player Core 2]] pg. 298

**Price** 3 gp

---

This snare consists of a hidden canister of [[Equipment/Caltrops (Player Core)|caltrops]] attached to a trip wire. When the snare is triggered, it flings the caltrops into either the snare's square or a square adjacent to the snare. You choose which square when you set up the snare.  
If the caltrops scatter into the same square as a creature, that creature must attempt the [[Rules/Skills/Acrobatics (Player Core)|Acrobatics]] check immediately.

**Craft Requirements** Supply a container of [[Equipment/Caltrops (Player Core)|caltrops]].
