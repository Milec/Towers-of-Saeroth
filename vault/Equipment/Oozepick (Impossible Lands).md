# Oozepick  *Item 4+*

**Traits** [[Traits/Uncommon]], [[Traits/Alchemical]], [[Traits/Consumable]]

**Source** [[Sources/Impossible Lands]] pg. 306

**Usage** held in 1 hand

**Bulk** L

**Access** Characters from Nex have access to this item.

**Activate**

single action

Interact

---

You can pour this silver ooze into a lock or similar mechanism to create a set of malleable lockpicks and tools that conform to internal mechanisms. The ooze is treated as a set of [[Equipment/Thieves' Tools|thieves' tools]] that last for 1 hour and provide a +2 item bonus to [[Rules/Skills/Thievery]] checks to [[Actions/Pick a Lock|Pick Lock]] or [[Actions/Disable a Device]] against the mechanism into which they were first poured.
