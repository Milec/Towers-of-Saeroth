# Artisan's Toolkit  *Item 0+*

**Source** [[Sources/Player Core]] pg. 287

**Price** 4 gp

**Hands** -1

**Bulk** 2

---

You need this toolkit to create items from raw materials with the [[Actions/Craft]] skill. Different sets are needed for different work, as determined by the GM; for example, a blacksmith's toolkit differs from a woodworker's toolkit. If you wear your artisan's toolkit, you can draw and replace it as part of the action that uses it.

You can use a toolkit with 1 hand if you’re wearing it or 2 if you’re holding it. [[Rules/Wearing Toolkits|See here for details]].
