# Thieves' Tools  *Item 0+*

**Source** [[Sources/Core Rulebook]] pg. 291

**Price** 3 gp

**Hands** 2

**Bulk** L

---

You need thieves' tools to [[Actions/Pick a Lock|Pick Locks]] or [[Actions/Disable a Device|Disable Devices]] (of some types) using the [[Rules/Skills/Thievery]] skill. If your thieves' tools are broken, you can repair them by replacing the lock picks with replacement picks appropriate to your tools; this doesn't require using the [[Actions/Repair]] action. If you wear your thieves' tools, you can draw and replace them as part of the action that uses them.

You can use a set of tools with 1 hand if you're [[Rules/Wearing Tools|wearing them]] or 2 if you're holding them.

You gain a +1 item bonus to [[Rules/Sidebars/Being Stealthy|Stealth]] checks to [[Actions/Conceal an Object|Conceal]] these tools. They otherwise function as infiltrator thieves' tools.
