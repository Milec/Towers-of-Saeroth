# Repair Toolkit  *Item 0+*

**Source** [[Sources/Player Core]] pg. 290

---

A repair toolkit allows you to perform simple repairs while traveling. It contains a portable anvil, tongs, woodworking tools, a whetstone, and oils for conditioning leather and wood. You can use a repair toolkit to [[Actions/Repair]] items using the [[Rules/Sidebars/Crafting Example|Crafting]] skill. You can draw and replace a worn repair toolkit as part of the action that uses it.
