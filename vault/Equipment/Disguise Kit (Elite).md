# Disguise Kit  *Item 0+*

**Source** [[Sources/Player Core]] pg. 288

**Price** 2 gp

**Hands** 2

**Bulk** L

---

This small wooden box contains cosmetics, false facial hair, spirit gum, and a few simple wigs. You usually need a disguise kit to set up a disguise in order to [[Actions/Impersonate]] someone using the [[Rules/Skills/Deception]] skill. If you've crafted a large number of disguises, you can replenish your cosmetics supply with replacement cosmetics suitable for the type of your disguise kit. You can draw and replace a worn disguise kit as part of the action that uses it.
