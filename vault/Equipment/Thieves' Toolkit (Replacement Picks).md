# Thieves' Toolkit  *Item 0+*

**Source** [[Sources/Player Core]] pg. 292

**Price** 3 gp

**Hands** -1

**Bulk** L

---

You need a thieves' toolkit to [[Actions/Pick a Lock|Pick Locks]] or [[Actions/Disable a Device|Disable Devices]] (of some types) using the [[Rules/Skills/Thievery]] skill. If your thieves' toolkit is [[Rules/Conditions/Broken|broken]], you can repair it by replacing the lock picks with replacement picks appropriate to your toolkit; this doesn't require using the [[Actions/Repair]] action. If you wear your thieves' toolkit, you can draw and replace it as part of the action that uses it.

You can use a toolkit with 1 hand if you’re wearing it or 2 if you’re holding it. [[Rules/Wearing Toolkits|See here for details]].
