# Serpent Oil  *Item 3+*

**Traits** [[Traits/Consumable]], [[Traits/Magical]], [[Traits/Oil]]

**Source** [[Sources/Treasure Vault (Remastered)]] pg. 87

**Usage** held in 2 hands

**Bulk** L

**Activate**

single action

([[Traits/Manipulate|manipulate]])

---

This glistening oil has a green hue and tiny snake scales floating within. If you slather _serpent oil_ on a Tiny object that is snakelike in shape, from a stick to a scarf, the object transforms into a [[Bestiary/Viper|viper]], keeping some of the same colors and patterns of the original item. If placed on other objects, the oil fails and is wasted. This false snake has the [[Traits/Minion|minion]] trait. It remains in snake form for 1 minute before returning to its object state. If slain, the item returns to its original form, unharmed.
