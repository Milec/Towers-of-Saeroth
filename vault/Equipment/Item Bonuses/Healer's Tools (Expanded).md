# Healer's Tools  *Item 0+*

**Source** [[Sources/Core Rulebook]] pg. 290

**Price** 5 gp

**Hands** 2

**Bulk** 1

---

This kit of bandages, herbs, and suturing tools is necessary for [[Rules/Skills/Medicine]] checks to [[Actions/Administer First Aid]], [[Actions/Treat Disease]], [[Actions/Treat Poison]], or [[Actions/Treat Wounds]].  If you wear your healer's tools, you can draw and replace them as part of the action that uses them.

You can use a set of tools with 1 hand if you're [[Rules/Wearing Tools|wearing them]] or 2 if you're holding them.
