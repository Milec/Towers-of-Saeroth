# Repair Kit  *Item 0+*

**Source** [[Sources/Core Rulebook]] pg. 291

---

A repair kit allows you to perform simple repairs while traveling. It contains a portable anvil, tongs, woodworking tools, a whetstone, and oils for conditioning leather and wood. You can use a repair kit to [[Actions/Repair]] items using the [[Rules/Sidebars/Crafting Example|Crafting]] skill. You can draw and replace a worn repair kit as part of the action that uses it.
