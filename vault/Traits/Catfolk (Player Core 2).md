# Catfolk  *Trait*

**Source** [[Sources/Player Core 2]] pg. 315

A creature with this trait is a member of the [[Ancestries/Catfolk (Player Core 2)|catfolk]] ancestry. Catfolk are humanoids with [[Bestiary/Families/Cat (Monster Core)|feline]] features. An ability with this trait can be used or selected only by catfolk. An item with this trait is created and used by catfolk.
