# Tripkee  *Trait*

**Source** [[Sources/Player Core 2]] pg. 319

A creature with this trait is a member of the [[Ancestries/Tripkee|tripkee]] ancestry. Tripkees are a family of froglike humanoids. An ability with this trait can be used or selected only by tripkees. An item with this trait is created and used by tripkees.
