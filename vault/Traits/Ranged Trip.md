# Ranged Trip  *Trait*

**Source** [[Sources/Advanced Player's Guide]] pg. 269

This weapon can be used to [[Actions/Trip]] with the [[Rules/Sidebars/Falling|Athletics]] skill at a distance up to the weapon's first range increment. The skill check takes a –2 circumstance penalty. You can add the weapon's item bonus to attack rolls as a bonus to the check. As with using a melee weapon to trip, a ranged trip doesn't deal any damage when used to Trip. This trait usually appears only on a [[Traits/Thrown|thrown]] weapon.
