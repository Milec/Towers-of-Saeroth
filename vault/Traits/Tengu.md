# Tengu  *Trait*

**Source** [[Sources/Advanced Player's Guide]] pg. 270

A creature with this trait is a member of the tengu ancestry. Tengus are [[Traits/Humanoid|humanoids]] who resemble birds. An ability with this trait can be used or selected only by tengus. An item with this trait is created and used by tengus.
