# Skill  *Trait*

**Source** [[Sources/Core Rulebook]] pg. 636

A [[Traits/General|general]] feat with the skill trait improves your skills and their actions or gives you new actions for a skill. A feat with this trait can be selected when a class grants a skill feat or general feat. Archetype feats with the skill trait can be selected in place of a skill feat if you have that archetype's dedication feat.
