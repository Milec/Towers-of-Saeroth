# Catfolk  *Trait*

**Source** [[Sources/Advanced Player's Guide]] pg. 266

A creature with this trait is a member of the [[Rules/Sidebars/Other Catfolk|catfolk]] ancestry. Catfolk are [[Traits/Humanoid|humanoids]] with feline features. An ability with this trait can be used or selected only by catfolk. An item with this trait is created and used by catfolk.
