# Tiefling  *Trait*

**Source** [[Sources/Advanced Player's Guide]] pg. 270

A creature with this trait has the tiefling versatile heritage. Tieflings are [[Bestiary/Families/Planar Scion|planar scions]] descended from [[Traits/Fiend|fiends]]. An ability with this trait can be used or selected only by tieflings.
