# Ratfolk  *Trait*

**Source** [[Sources/Player Core 2]] pg. 317

A creature with this trait is a member of the [[Ancestries/Ratfolk (Player Core 2)|ratfolk]] ancestry. Ratfolk are humanoids who resemble rats. An ability with this trait can be used or selected only by ratfolk.
