# Hobgoblin  *Trait*

**Source** [[Sources/Player Core 2]] pg. 316

A creature with this trait is a tall, militaristic goblinoid. [[Ancestries/Hobgoblin (Player Core 2)|Hobgoblins]] tend to have [[Rules/Darkvision and Greater Darkvision (Player Core)|darkvision]]. An ability with this trait can be used or selected only by hobgoblins. An item with this trait is created and used by hobgoblins.
