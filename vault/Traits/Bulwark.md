# Bulwark  *Trait*

**Source** [[Sources/Core Rulebook]] pg. 274

The armor covers you so completely that it provides benefits against some damaging effects. On Reflex saves to avoid a damaging effect, such as a _[[Spells/Fireball|fireball]]_, you add a +3 modifier instead of your Dexterity modifier.
