# Consecration  *Trait*

**Source** [[Sources/Core Rulebook]] pg. 630

A consecration spell enhances an area for an extended period of time. A given area can have only a single consecration effect at a time. The new effect attempts to [[Rules/Counteracting (Core Rulebook)|counteract]] any existing one in areas of overlap.
