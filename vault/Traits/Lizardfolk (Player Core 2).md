# Lizardfolk  *Trait*

**Source** [[Sources/Player Core 2]] pg. 317

A creature with this trait is a member of the [[Ancestries/Lizardfolk (Player Core 2)|lizardfolk]] ancestry, a family of reptilian humanoids. An ability with this trait can be used or selected only by lizardfolk.
