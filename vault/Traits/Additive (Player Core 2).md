# Additive  *Trait*

**Source** [[Sources/Player Core 2]] pg. 61

Feats with the additive trait allow you to add special substances to alchemical consumables you create when you use [[Actions/Quick Alchemy (Player Core 2)|Quick Alchemy]] to create a consumable (you can't use additives with quick vials). You can add only one additive to a single alchemical item, you can add an additive only once per round, and most additive abilities specify a subset of alchemical consumables you can add them to.
