# Aasimar  *Trait*

**Source** [[Sources/Advanced Player's Guide]] pg. 266

A creature with this trait has the aasimar versatile heritage. Aasimars are [[Bestiary/Families/Planar Scion|planar scions]] descended from [[Traits/Celestial|celestial]] beings. An ability with this trait can be used or selected only by aasimars.
