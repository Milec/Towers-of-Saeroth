# Tengu  *Trait*

**Source** [[Sources/Player Core 2]] pg. 318

A creature with this trait is a member of the [[Ancestries/Tengu (Player Core 2)|tengu]] ancestry. Tengu are humanoids who resemble crows. An ability with this trait can be used or selected only by tengu. An item with this trait is created and used by tengu.
