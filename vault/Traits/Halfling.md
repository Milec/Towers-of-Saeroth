# Halfling  *Trait*

**Source** [[Sources/Core Rulebook]] pg. 632

A creature with this trait is a member of the [[Ancestries/Halfling|halfling]] ancestry. These small people are friendly wanderers considered to be lucky. An ability with this trait can be used or selected only by halflings. A weapon with this trait is created and used by halflings.
