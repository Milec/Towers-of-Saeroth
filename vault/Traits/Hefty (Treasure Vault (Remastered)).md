# Hefty  *Trait*

**Source** [[Sources/Treasure Vault (Remastered)]] pg. 219

A hefty shield is so heavy that raising it takes more effort. [[Actions/Raise a Shield|Raising a Shield]] with the hefty trait is a two-action activity unless your Strength modifier equals or exceeds the number with the trait.
