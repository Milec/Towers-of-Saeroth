# Kholo  *Trait*

**Source** [[Sources/Player Core 2]] pg. 317

A creature with this trait is a member of the [[Ancestries/Kholo|kholo]] ancestry —humanoids that resemble [[Bestiary/Families/Hyena (Monster Core)|hyenas]]. An ability with this trait can be used or selected only by kholos. An item with this trait is created and used by kholos.
