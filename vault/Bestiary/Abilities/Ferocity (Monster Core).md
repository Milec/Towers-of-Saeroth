# Ferocity ⤾  *Creature Ability*

**Source** [[Sources/Monster Core]] pg. 359

**Trigger** The monster is reduced to 0 HP; **Effect** The monster avoids being knocked out and remains at 1 HP, but its [[Rules/Conditions/Wounded (Player Core)|wounded]] value increases by 1. When it is wounded 3, it can no longer use this ability.
