# Low-Light Vision  *Creature Ability*

**Source** [[Sources/Monster Core]] pg. 359

The monster can see in [[Rules/Dim Light (Player Core)|dim light]] as though it were [[Rules/Bright Light (Player Core)|bright light]], so it ignores the [[Rules/Conditions/Concealed (Player Core)|concealed]] condition due to dim light.
