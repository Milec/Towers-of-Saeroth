# Zombie  *Creature Adjustment*

**Source** [[Sources/Book of the Dead]] pg. 73

A [[Bestiary/Families/Zombie|zombified]] creature is a mindless, rotting corpse that attacks everything it perceives.

- Add the [[Traits/Mindless|mindless]], [[Traits/Undead|undead]], and [[Traits/Zombie|zombie]] traits.
- Increase the creature's HP based on its level.
- Add the following immunities: [[Traits/Death|death]] effects, [[Traits/Disease|disease]], [[Traits/Mental|mental]], [[Rules/Conditions/Paralyzed|paralyzed]], [[Traits/Poison|poison]], [[Rules/Conditions/Unconscious|unconscious]].
- Add the following weaknesses, with a value based on its level: [[Traits/Positive|positive]], slashing.
- Add the following abilities. [[Bestiary/Abilities/Darkvision]] [[Bestiary/Abilities/Negative Healing]] **Slow** A zombie is permanently [[Rules/Conditions/Slowed|slowed 1]] and can't use reactions.
