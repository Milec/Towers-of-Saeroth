# Luminous Sprite  *Heritage*

**Source** [[Sources/Ancestry Guide]] pg. 129

You glow with magical luminance. You naturally shed light as a torch; this light has the [[Traits/Evocation|evocation]], [[Traits/Light|light]], and [[Traits/Primal|primal]] traits. You can extinguish, rekindle, or change the color of this light using a single action, which has the [[Traits/Concentrate|concentrate]] trait.
