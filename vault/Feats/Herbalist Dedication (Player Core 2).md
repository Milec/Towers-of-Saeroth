# Herbalist Dedication  *Feat 2*

**Traits** [[Traits/Archetype (Player Core)|Archetype]], [[Traits/Dedication (Player Core)|Dedication]]

**Source** [[Sources/Player Core 2]] pg. 202

**Archetype** [[Archetypes/Herbalist (Player Core 2)|Herbalist]]

**Prerequisites**
[[Feats/Natural Medicine (Player Core)|Natural Medicine]]; Trained in [[Rules/Skills/Nature (Player Core)|Nature]]

---

You can create natural remedies. You gain the [[Rules/Alchemical Archetypes (Player Core 2)|advanced alchemy benefits]]. You can use advanced alchemy to create 4 [[Traits/Alchemical (Player Core)|alchemical]] [[Traits/Consumable (Player Core)|consumables]] with the [[Traits/Healing (Player Core)|healing]] trait, though the number is reduced by 2 if you didn’t make your [[Rules/Daily Preparations (GM Core)|daily preparations]] in the wilderness. These consumables are called your herbal items. You remember herbal item [[Rules/Formulas (Player Core)|formulas]] and don’t need a [[Equipment/Formula Book (Blank) (Player Core)|formula book]] for them.

You become an expert in [[Rules/Skills/Nature (Player Core)|Nature]] and can use Nature instead of [[Rules/Skills/Crafting (Player Core)|Crafting]] to [[Actions/Craft (Player Core)|Craft]] alchemical consumables with the healing trait. You don’t need to be trained in Crafting to do so, and you can use [[Equipment/Healer's Toolkit|healer’s tools]] instead of [[Equipment/Alchemist's Toolkit|alchemist’s tools]].
