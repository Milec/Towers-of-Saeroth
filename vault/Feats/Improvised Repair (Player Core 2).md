# Improvised Repair three actions  *Feat 3*

**Traits** [[Traits/General (Player Core)|General]]

**Source** [[Sources/Player Core 2]] pg. 231

---

You can hastily patch damaged equipment together, but the temporary fix lacks the full care required for lasting repairs. You patch together a broken item possessed by you or an adjacent willing creature. Until the item takes damage again, it still functions as a [[Rules/Shoddy Items (Player Core)|shoddy]] item of its type. If it's a magic item or another item with activations, it can't be activated while patched together, but can be used for normal functions (such as [[Actions/Strike (Player Core)|Striking]] with a weapon or using [[Feats/Shield Block (Player Core)|Shield Block]] with a shield). This activity restores no Hit Points, so the item is easy to [[Rules/Item Damage (Player Core)|destroy]] . Once the item is [[Actions/Repair (Player Core)|Repaired]] normally such that it is no longer [[Rules/Conditions/Broken (Player Core)|broken]], it is also no longer shoddy.
