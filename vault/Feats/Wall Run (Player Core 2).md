# Wall Run single action  *Feat 8*

**Traits** [[Traits/Monk (Player Core)|Monk]]

**Source** [[Sources/Player Core 2]] pg. 124

**Archetype** [[Rules/Sidebars/Roleplaying a Ghoul|Ghoul]] (Level 10)

---

You defy gravity, traversing vertical planes as easily as the ground. Stride up to your Speed. You must start your movement on a horizontal surface. During this movement, you can run up vertical surfaces, like walls, at your full Speed. If you end the Stride off the ground, you fall after taking your next action or when your turn ends, whichever comes first (though you can [[Actions/Grab an Edge (Player Core)|Grab an Edge]], if applicable). If you have [[Feats/Water Step]] or a similar ability, Wall Run lets you run along flimsy vertical surfaces, as well as vertical liquids, such as a waterfall.
