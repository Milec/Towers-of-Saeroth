# Lobbed Attack single action  *Feat 8*

> [!warning] Spoilers
> May contain spoilers from Extinction Curse

**Traits** [[Traits/Uncommon]], [[Traits/Archetype]]

**Source** [[Sources/Pathfinder -151- The Show Must Go On|Pathfinder #151: The Show Must Go On]] pg. 74

**Archetype** [[Archetypes/Juggler]]

**Prerequisites**
Master in [[Rules/Skills/Performance]]; [[Feats/Juggler Dedication]]

**Requirements**
You are Juggling a [[Traits/Thrown|thrown]] weapon.

---

You make a thrown ranged Strike with the required weapon, using the weapon’s normal range increment. This attack doesn’t trigger reactions, and if the target has never seen you use this feat before, the target is [[Rules/Conditions/Flat-Footed|flat-footed]] against this attack.
