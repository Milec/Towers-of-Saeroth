# Ten Lives  *Feat 17*

**Traits** [[Traits/Catfolk (Player Core 2)|Catfolk]]

**Source** [[Sources/Player Core 2]] pg. 11

**Prerequisites**
[[Feats/Evade Doom (Player Core 2)|Evade Doom]]

---

When your character would die, you can attempt a DC 17 flat check. On a success, you're instead reduced to 0 HP and a [[Rules/Conditions/Dying (Player Core)|dying]] value 1 less than what would normally kill you (typically dying 3). This doesn't change the result for any other creature affected.
