# Brandishing Draw single action  *Feat 2*

**Traits** [[Traits/Swashbuckler (Player Core 2)|Swashbuckler]]

**Source** [[Sources/Player Core 2]] pg. 165

---

You draw and attack with the same motion. You Interact to draw a weapon, then either Strike or use a one-action [[Traits/Finisher (Player Core 2)|finisher]]. You must still meet any other requirements to use a finisher, and any Strike you make must be made with the weapon you drew.
