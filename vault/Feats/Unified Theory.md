# Unified Theory  *Feat 15*

**Traits** [[Traits/General]], [[Traits/Skill]]

**Source** [[Sources/Core Rulebook]] pg. 268

**Prerequisites**
Legendary in [[Rules/Skills/Arcana]]

---

You've started to make a meaningful connection about the common underpinnings of the four traditions of magic and magical essences, allowing you to understand them all through an arcane lens. Whenever you use a skill action or a skill feat that requires a [[Rules/Sidebars/Commanded Animals|Nature]], [[Rules/Skills/Occultism]], or [[Rules/Skills/Religion]] check, depending on the magic tradition, you can use [[Rules/Skills/Arcana]] instead. If you would normally take a penalty or have a higher DC for using Arcana on other magic (such as when using [[Actions/Identify Magic]]), you no longer do so.
