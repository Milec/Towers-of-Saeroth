# Basic Scroll Cache  *Feat 6*

**Traits** [[Traits/Archetype (Player Core)|Archetype]]

**Archetype** [[Archetypes/Scroll Trickster (Player Core 2)|Scroll Trickster]]

**Prerequisites**
[[Feats/Scroll Trickster Dedication (Player Core 2)|Scroll Trickster Dedication]]

---

You have a vast and overflowing collection of [[Rules/Category Pages/Adventuring Gear|scroll]]  scraps, riddled with errors and misspellings and leaking energy like a sieve. With enough care, you can coax these scroll scraps into functioning—briefly. Each day during your daily preparations, you can create a single temporary scroll containing a 1st-rank spell. The spell must be a common spell, a spell to which you have access, or a spell you are able to cast, and you must be trained in the skill corresponding to at least one of the spell's traditions. You can use [[Actions/Learn a Spell (Player Core)|Learn a Spell]] to add spells to those you can use with this feat, even if you aren't a spellcaster. This scroll is an unstable, temporary item and loses its magic the next time you make your daily preparations if you haven't already used it. This temporary scroll can't be used to Learn the Spell.  
At 8th level, add a second temporary scroll containing a 2nd-rank spell.
