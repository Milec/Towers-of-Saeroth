# Demon-Hunting Companion  *Feat 4*

**Traits** [[Traits/Archetype]]

**Source** [[Sources/Shining Kingdoms]] pg. 146

**Archetype** [[Archetypes/Wylderheart]]

**Prerequisites**
[[Feats/Wylderheart Dedication]]

---

You gain a young [[Rules/Assistive Items (Player Core)|animal companion]] that has been specially trained to help you fight [[Bestiary/Families/Demon (Monster Core)|demons]]. You can choose any common animal companion, which gains [[Bestiary/Abilities/Scent (Monster Core)|scent]] as an [[Rules/Imprecise Senses (Player Core)|imprecise sense]] with a range of 30 feet that can be used only to smell fiends. If the animal companion already has scent, it gains a +2 circumstance bonus to Perception when using scent against [[Traits/Fiend (Player Core)|fiends]].
