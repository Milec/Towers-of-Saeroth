# Multilingual Cipher  *Feat 4*

**Traits** [[Traits/Archetype (Player Core)|Archetype]], [[Traits/Skill (Player Core)|Skill]]

**Source** [[Sources/Player Core 2]] pg. 203

**Archetype** [[Archetypes/Linguist (Player Core 2)|Linguist]]

**Prerequisites**
[[Feats/Linguist Dedication (Player Core 2)|Linguist Dedication]]; Expert in [[Rules/Skills/Society (Player Core)|Society]]

---

You use multiple languages to create and break codes. You gain a +1 circumstance bonus to [[Actions/Decipher Writing (Player Core)|Decipher Writing]]. If another creature attempts to Decipher Writing you encoded, they take a –2 circumstance penalty unless they speak all the languages you used when you created the writing.
