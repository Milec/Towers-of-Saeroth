# Quick Bomber single action  *Feat 1*

**Traits** [[Traits/Alchemist (Player Core 2)|Alchemist]]

**Source** [[Sources/Player Core 2]] pg. 63

---

You keep your bombs and bomb-related reagents in easy-to-reach pouches from which you draw without thinking. You [[Actions/Interact (Player Core)|Interact]] to draw a bomb, draw a versatile vial, or use [[Actions/Quick Alchemy (Player Core 2)|Quick Alchemy]] to create a bomb, then [[Actions/Strike (Player Core)|Strike]] with the bomb. If you have the ability to create more than one bomb at a time with Quick Alchemy (such as from the double brew class feature), you can Strike with only one of the bombs you create with this action.
