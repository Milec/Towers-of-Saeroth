# Nimble Shield Hand  *Feat 6*

**Traits** [[Traits/Archetype]]

**Source** [[Sources/Advanced Player's Guide]] pg. 159

**Archetype** [[Archetypes/Bastion]]

**Prerequisites**
[[Feats/Bastion Dedication]]

---

You are so used to wielding a shield that you can do so even while using the hand that's holding it for other purposes. The hand you use to wield a shield counts as a free hand for the purposes of the Interact action. You can also hold another object in this hand (but you still can't use it to wield a weapon). This benefit doesn't apply to [[Equipment/Shields/Tower Shield|tower shields]], which are still too cumbersome.
