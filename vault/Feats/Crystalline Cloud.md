# Crystalline Cloud  *Feat 9*

**Traits** [[Traits/Aphorite]]

**Source** [[Sources/Ancestry Guide]] pg. 77

**Prerequisites**
[[Feats/Crystalline Dust]]

---

When you use Crystalline Dust, you can spend one additional action to disperse the motes as a 10-foot-radius cloud centered on you instead of as haze; the activity gains the [[Traits/Concentrate|concentrate]] trait. All creatures within the cloud become [[Rules/Conditions/Concealed|concealed]], and all creatures outside the cloud become concealed to creatures within it.
