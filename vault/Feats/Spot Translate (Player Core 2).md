# Spot Translate ⤾  *Feat 4*

**Traits** [[Traits/Archetype (Player Core)|Archetype]], [[Traits/Auditory (Player Core)|Auditory]], [[Traits/Linguistic (Player Core)|Linguistic]]

**Source** [[Sources/Player Core 2]] pg. 203

**Archetype** [[Archetypes/Linguist (Player Core 2)|Linguist]]

**Prerequisites**
[[Feats/Linguist Dedication (Player Core 2)|Linguist Dedication]]

**Trigger**
Another creature within 60 feet uses a [[Traits/Linguistic (Player Core)|linguistic]] effect in a language you understand.

---

You bridge a language gap, repeating the message in a different language that you know. Choose a language you understand to repeat the message in. The [[Traits/Linguistic (Player Core)|linguistic]] effect counts as both languages, rather than only the language the triggering creature is using, potentially allowing it to affect a wider range of creatures. As normal, you can translate normal speech without Spot Translate and without using a reaction, but this reaction allows you to apply the benefits of translation to spells and actions such as command or [[Actions/Demoralize (Player Core)|Demoralize]].
