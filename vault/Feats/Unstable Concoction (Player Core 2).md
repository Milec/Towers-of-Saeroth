# Unstable Concoction  *Feat 10*

**Traits** [[Traits/Additive (Player Core 2)|Additive]], [[Traits/Alchemist (Player Core 2)|Alchemist]]

**Source** [[Sources/Player Core 2]] pg. 67

---

You can mix a wondrous yet volatile liquid into an [[Traits/Alchemical (Player Core)|alchemical]] [[Traits/Consumable (Player Core)|consumable]] if it has an initial effect that uses dice. You [[Rules/Increasing Die Size|increase the size of any dice]] for the item's initial effect by one step. For instance, you could increase damage from a [[Equipment/Alchemist's Fire (Player Core 2)|moderate alchemist's fire]] to 2d10 or healing from a [[Equipment/Elixir of Life (Player Core 2)|moderate elixir of life]] to 5d8+12. Because this affects only initial dice, it wouldn't increase unarmed attack damage from a [[Equipment/Bestial Mutagen (Player Core 2)|bestial mutagen]], [[Rules/Sidebars/Persistent Damage Rules|persistent damage]] from an [[Equipment/Acid Flask (Player Core 2)|acid flask]], and the like. When this item is activated, the creature activating it must succeed at a DC 10 [[Rules/Flat Checks|flat check]] or take acid damage equal to the item's level.
