# Doctor's Visitation single action or two actions  *Feat 4*

**Traits** [[Traits/Archetype (Player Core)|Archetype]], [[Traits/Flourish (Player Core)|Flourish]]

**Source** [[Sources/Player Core 2]] pg. 208

**Archetype** [[Archetypes/Medic (Player Core 2)|Medic]]

**Prerequisites**
[[Feats/Medic Dedication (Player Core 2)|Medic Dedication]]

---

You move to provide immediate care to those who need it. You [[Actions/Stride (Player Core)|Stride]], then use [[Feats/Battle Medicine (Player Core)|Battle Medicine]] or [[Actions/Treat Poison (Player Core)|Treat Poison]]. You can spend 2 actions for Doctor’s Visitation to instead Stride and then use either [[Actions/Administer First Aid (Player Core)|Administer First Aid]] or [[Feats/Treat Condition (Player Core 2)|Treat Condition]] (if you have that feat).
