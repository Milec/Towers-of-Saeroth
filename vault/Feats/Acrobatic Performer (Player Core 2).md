# Acrobatic Performer  *Feat 1*

**Traits** [[Traits/General (Player Core)|General]], [[Traits/Skill (Player Core)|Skill]]

**Source** [[Sources/Player Core 2]] pg. 226

**Prerequisites**
Trained in [[Rules/Skills/Acrobatics (Player Core)|Acrobatics]]

---

You're an incredible acrobat, evoking wonder and enrapturing audiences with your prowess. You can roll an Acrobatics check instead of a [[Rules/Skills/Performance (Player Core)|Performance]] check when using the [[Actions/Perform (Player Core)|Perform]] action. If you are trained in both Acrobatics and Performance, you gain a +1 circumstances bonus on Acrobatics checks made to Perform.
