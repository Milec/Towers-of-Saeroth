# Poisoner Dedication  *Feat 2*

**Traits** [[Traits/Archetype (Player Core)|Archetype]], [[Traits/Dedication (Player Core)|Dedication]]

**Source** [[Sources/Player Core 2]] pg. 210

**Archetype** [[Archetypes/Poisoner (Player Core 2)|Poisoner]]

**Prerequisites**
Trained in [[Rules/Skills/Crafting (Player Core)|Crafting]]

---

You make a point of always having a few toxins near at hand—you never know when some [[Equipment/Arsenic (Player Core 2)|arsenic]] or the like might prove useful. You gain the [[Rules/Alchemical Archetypes|advanced alchemy benefits]]. You can use advanced alchemy to create four [[Rules/Category Pages/Adventuring Gear|alchemical poison]]  [[Traits/Consumable (Player Core)|consumables]] each day. You remember alchemical poison formulas and don't need a formula book for them.
