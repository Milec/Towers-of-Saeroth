# Armament Paragon  *Feat 20*

**Traits** [[Traits/Champion (Player Core 2)|Champion]]

**Source** [[Sources/Player Core 2]] pg. 99

**Prerequisites**
blessed armament

---

Add the following property runes to the list you can choose for your blessed armament: animated, [[Equipment/Fearsome (GM Core)|_greater fearsome_]], [[Equipment/Grievous (GM Core)|_grievous_]], [[Equipment/Keen (GM Core)|_keen_]], and [[Equipment/Vitalizing|_greater vitalizing_]]. If you have the Radiant Armament feat, add [[Equipment/Astral|_greater astral_]] and [[Equipment/Brilliant (GM Core)|_greater brilliant_]] to the list as well. In addition, you can change the rune you've selected for the day to a different rune from your list as a single action that has the [[Traits/Concentrate (Player Core)|concentrate]] and [[Traits/Divine (Player Core)|divine]] traits. Changing the rune doesn't restore abilities that can be used only a limited number of times.
