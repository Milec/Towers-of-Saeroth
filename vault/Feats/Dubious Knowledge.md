# Dubious Knowledge  *Feat 1*

**Traits** [[Traits/General]], [[Traits/Skill]]

**Source** [[Sources/Core Rulebook]] pg. 260

**Prerequisites**
trained in a skill with the [[Actions/Recall Knowledge]] action

---

You're a treasure trove of information, but not all of it comes from reputable sources. When you fail (but don't critically fail) a [[Actions/Recall Knowledge]] check using any skill, you learn a bit of true knowledge and a bit of erroneous knowledge, but you don't have any way to differentiate which is which.
