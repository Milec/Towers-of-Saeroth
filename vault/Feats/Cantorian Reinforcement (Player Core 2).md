# Cantorian Reinforcement  *Feat 1*

**Traits** [[Traits/Hobgoblin (Player Core 2)|Hobgoblin]]

**Source** [[Sources/Player Core 2]] pg. 14

---

The life energy that helped create the first hobgoblins is particularly potent in you, protecting you from ongoing maladies. If you roll a success on a saving throw against a [[Traits/Disease (Player Core)|disease]] or [[Traits/Poison (Player Core)|poison]], you get a critical success instead. If you have a different ability that would improve the save in this way (such as the [[Classes/Class Features/Ancestry and Background (class-feature-154)|battle hardened fighter class feature]]), if you roll a critical failure on the save you get a failure instead.
