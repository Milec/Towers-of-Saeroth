Your faith enhances your ability to remove conditions. Add the following options to the list of conditions you can [[Rules/Counteracting (Core Rulebook)|counteract]] for any type of mercy you can grant. **Mercy of the Body** [[Rules/Conditions/Drained (Player Core)|drained]], [[Rules/Conditions/Slowed (Player Core)|slowed]]; if you're 16th level, add [[Rules/Conditions/Stunned (Player Core)|stunned]]; **Mercy of Grace** [[Rules/Conditions/Immobilized (Player Core)|immobilized]], [[Rules/Conditions/Restrained (Player Core)|restrained]], slowed; if you're 12th level, add [[Rules/Conditions/Petrified (Player Core)|petrified]]; if you're 16th level, add stunned; **Mercy of the Mind** [[Rules/Conditions/Confused (Player Core)|confused]], [[Rules/Conditions/Controlled (Player Core)|controlled]], slowed; if you're 16th level, add [[Rules/Conditions/Doomed (Player Core)|doomed]] and stunned.
