# Dual-Weapon Reload  *Feat 4*

**Traits** [[Traits/Archetype (Player Core)|Archetype]]

**Source** [[Sources/Player Core 2]] pg. 196

**Archetypes** [[Archetypes/Dual-Weapon Warrior (Player Core 2)|Dual-Weapon Warrior]], [[Archetypes/Crossbow Infiltrator]] (Level 6)

**Prerequisites**
[[Feats/Dual-Weapon Warrior Dedication (Player Core 2)|Dual-Weapon Warrior Dedication]]

---

You carry your ammunition in a way that allows you to reload while holding two weapons. While you're wielding two one-handed weapons, each in a different hand, you don't need a free hand to reload a one-handed ranged weapon you're wielding.
