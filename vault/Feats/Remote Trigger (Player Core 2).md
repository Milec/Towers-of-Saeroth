# Remote Trigger  *Feat 6*

**Traits** [[Traits/Archetype (Player Core)|Archetype]]

**Source** [[Sources/Player Core 2]] pg. 216

**Archetype** [[Archetypes/Snarecrafter (Player Core 2)|Snarecrafter]]

**Prerequisites**
[[Feats/Snarecrafter Dedication (Player Core 2)|Snarecrafter Dedication]]

---

You've learned how to trigger [[Traits/Snare (Player Core 2)|snares]] from afar, creating ranged hazards to assail your opponents and allowing you to disarm enemies' snares harmlessly. You can [[Actions/Strike (Player Core)|Strike]] a snare to trigger it prematurely. If you crafted the snare, you automatically hit. If someone else crafted it, attempt a ranged Strike against the [[Rules/Skills/Crafting (Player Core)|Crafting]] DC, triggering the snare only if you hit.
