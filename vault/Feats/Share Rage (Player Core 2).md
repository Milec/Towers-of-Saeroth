# Share Rage single action  *Feat 8*

**Traits** [[Traits/Auditory (Player Core)|Auditory]], [[Traits/Barbarian (Player Core 2)|Barbarian]], [[Traits/Rage (Player Core 2)|Rage]], [[Traits/Visual (Player Core)|Visual]]

**Source** [[Sources/Player Core 2]] pg. 81

**Requirements**
You haven’t used this ability since you last Raged.

---

You stoke an ally's fury. While you are raging, one willing creature within 30 feet gains the effects of the [[Actions/Rage (Player Core 2)|Rage]] action, except it can still use [[Traits/Concentrate (Player Core)|concentrate]] actions. It doesn't get any added benefits from your instinct, feats, or the like.
