# Alchemical Discoveries  *Feat 4*

**Traits** [[Traits/Investigator (Player Core 2)|Investigator]]

**Source** [[Sources/Player Core 2]] pg. 108

**Prerequisites**
[[Classes/Subclasses/Methodologies/Alchemical Sciences (Player Core 2)|alchemical sciences methodology]]

---

You've devoted extra time in the lab to improve your knowledge of alchemy. You learn the formulas for two [[Traits/Alchemical (Player Core)|alchemical items]] each time you level up instead of one; these must still be [[Rules/Category Pages/Adventuring Gear|elixirs]] or [[Rules/Category Pages/Adventuring Gear|tools]]. The number of versatile vials you can create each day increases by one if you're an expert in [[Rules/Skills/Crafting (Player Core)|Crafting]], two if you're a master, or three if you're legendary.
