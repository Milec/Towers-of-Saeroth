# Sonic Dash single action  *Feat 2*

**Source** [[Sources/Gatewalkers Player's Guide (Remastered)]] pg. 10

You bounce up and down once, then sprint forward. You [[Actions/Stride (Player Core)|Stride]] twice in a straight [[Rules/Line (Player Core)|line]]. You can use Sonic Dash while [[Actions/Burrow (Player Core)|Burrowing]], [[Actions/Climb (Player Core)|Climbing]], [[Actions/Fly (Player Core)|Flying]], or [[Actions/Swim (Player Core)|Swimming]] instead of Striding if you have the corresponding movement type.
