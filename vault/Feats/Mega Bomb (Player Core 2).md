# Mega Bomb  *Feat 20*

**Traits** [[Traits/Additive (Player Core 2)|Additive]], [[Traits/Alchemist (Player Core 2)|Alchemist]], [[Traits/Manipulate (Player Core)|Manipulate]]

**Source** [[Sources/Player Core 2]] pg. 69

---

You can add a highly explosive additive to an alchemical bomb to turn it into a mega bomb. Throwing this bomb takes a 2-action activity instead of a Strike. This isn't a Strike, and you don't make an attack roll. The mega bomb explodes in a 30-foot burst within 60 feet. It deals damage as if each creature were the primary target, with a [[Rules/Basic Saving Throws (Core Rulebook)|basic]] Reflex save. On a failed save, a creature also takes any extra effects that affect a primary target (such as [[Rules/Conditions/Off-Guard|off-guard]] from [[Equipment/Bottled Lightning (Player Core 2)|bottled lightning]]). Though all targets in the area take [[Traits/Splash (GM Core)|splash]] damage as primary targets, there is no further splash beyond that area.
