# Alchemical Discoveries  *Feat 4*

**Traits** [[Traits/Investigator]]

**Source** [[Sources/Advanced Player's Guide]] pg. 61

**Prerequisites**
[[Classes/Subclasses/Methodologies/Alchemical Sciences|alchemical sciences methodology]]

---

You've devoted extra time in the lab to improve your knowledge of alchemy. You learn the formulas for two alchemical items each time you level up instead of one; these must still be [[Rules/Category Pages/Adventuring Gear|elixirs]] or [[Rules/Category Pages/Adventuring Gear|tools]]. The number of versatile vials you can create each day increases by 1 if you're an expert in [[Rules/Sidebars/Crafting Example|Crafting]], 2 if you're a master, or 3 if you're legendary.
