# Barbarian Dedication  *Feat 2*

**Traits** [[Traits/Archetype (Player Core)|Archetype]], [[Traits/Dedication (Player Core)|Dedication]], [[Traits/Multiclass (Player Core)|Multiclass]]

**Source** [[Sources/Player Core 2]] pg. 176

**Archetype** [[Archetypes/Barbarian (Player Core 2)|Barbarian]]

**Prerequisites**
Constitution +2; Strength +2

---

You become trained in Athletics; if you were already trained in [[Rules/Sidebars/Multiple Attacks with Athletics (Player Core)|Athletics]], you instead become trained in a skill of your choice. You become trained in barbarian class DC. You can use the Rage action. While raging, you take a –1 penalty to AC. Choose an instinct as you would if you were a barbarian. You have that instinct for all purposes, but you don’t gain any of the other abilities it grants. If that instinct has anathema, you’re bound by them.
