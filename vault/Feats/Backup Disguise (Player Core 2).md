# Backup Disguise  *Feat 2*

**Traits** [[Traits/General (Player Core)|General]], [[Traits/Skill (Player Core)|Skill]]

**Source** [[Sources/Player Core 2]] pg. 227

**Prerequisites**
Expert in [[Rules/Skills/Deception (Player Core)|Deception]]

---

You have a specific disguise that you keep at the ready, worn underneath your outer garment. You can change into this disguise to [[Actions/Impersonate (Player Core)|Impersonate]] as a 3-action activity. If you are a master in Deception, it is instead a 2-action activity, and if you are legendary in Deception, it is a single action. You can create a new backup disguise by spending the normal amount of time it takes you to Impersonate, but you can have only one backup disguise at a time. Having a backup disguise doesn't allow you to remove your armor or any other complex piece of clothing any more quickly, but once you have those off, the disguise is readily available. Because you have the backup disguise at the ready, it's possible that a thorough search might reveal some elements of the [[Actions/Conceal an Object (Player Core)|disguise]].
