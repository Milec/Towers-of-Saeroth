# Make 'em Sweat  *Feat 12*

**Traits** [[Traits/Investigator (Player Core 2)|Investigator]]

**Source** [[Sources/Player Core 2]] pg. 111

**Prerequisites**
[[Classes/Subclasses/Methodologies/Interrogation (Player Core 2)|interrogation]] methodology

---

Your line of questioning lets a suspect know you can see right through them, shaking them to the core. When you succeed at using [[Actions/Pointed Question (Player Core 2)|Pointed Question]], the target is also [[Rules/Conditions/Frightened (Player Core)|frightened 1]] (or frightened 2 on a critical success). This added effect is an [[Traits/Emotion (Player Core)|emotion]] and [[Traits/Fear (Player Core)|fear]] effect, but the other effects of Pointed Question still apply even if the target is immune to fear.
