# Derring-do  *Feat 10*

**Traits** [[Traits/Fortune (Player Core)|Fortune]], [[Traits/Swashbuckler (Player Core 2)|Swashbuckler]]

**Source** [[Sources/Player Core 2]] pg. 167

---

When you compound panache with even more derring-do, it somehow tends to work out. When you already have panache, you can roll twice and use the higher result on checks to which the circumstance bonus from stylish combatant applies ([[Actions/Tumble Through (Player Core)|Tumble Through]] and any skill actions with the [[Traits/Bravado|bravado]] trait).
