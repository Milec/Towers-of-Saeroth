# Dual Finisher single action  *Feat 8*

**Traits** [[Traits/Finisher (Player Core 2)|Finisher]], [[Traits/Swashbuckler (Player Core 2)|Swashbuckler]]

**Source** [[Sources/Player Core 2]] pg. 167

**Requirements**
You wield two melee weapons, one in each hand.

---

You split your attacks. Make two melee Strikes, one with each required weapon, each against a different foe. If the second Strike is made with a non-[[Traits/Agile (Player Core)|agile]] weapon, it takes a –2 penalty. Increase your multiple attack penalty only after attempting both Strikes.
