# Illimitable Finisher single action  *Feat 20*

**Traits** [[Traits/Finisher (Player Core 2)|Finisher]], [[Traits/Flourish (Player Core)|Flourish]], [[Traits/Swashbuckler (Player Core 2)|Swashbuckler]]

**Source** [[Sources/Player Core 2]] pg. 169

---

Your strikes flow endlessly. Step and attempt a single one-action [[Traits/Finisher (Player Core 2)|finisher]]. This Strike gains the [[Traits/Bravado|bravado]] trait, possibly replenishing your panache; if you regain panache, you can immediately attempt another finisher as part of this action, ignoring the restriction of using actions with the [[Traits/Attack (Player Core)|attack]] trait after a finisher.
