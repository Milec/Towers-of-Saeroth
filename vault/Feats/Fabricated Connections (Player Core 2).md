# Fabricated Connections  *Feat 7*

**Traits** [[Traits/Archetype (Player Core)|Archetype]], [[Traits/Skill (Player Core)|Skill]]

**Source** [[Sources/Player Core 2]] pg. 195

**Archetypes** [[Archetypes/Dandy (Player Core 2)|Dandy]], [Venture-Gossip](https://2e.aonprd.com/Archetypes.aspx?ID=311) (Level 7)

**Prerequisites**
[[Feats/Dandy Dedication (Player Core 2)|Dandy Dedication]]; Master in [[Rules/Skills/Deception (Player Core)|Deception]]

---

You can lie about having taken an action so convincingly that you acquire all the tangible benefits of having successfully completed it. You can roll [[Rules/Skills/Deception (Player Core)|Deception]] in place of a different skill when attempting to [[Rules/Skills/Defense|Earn Income]], [[Actions/Make an Impression (Player Core)|Make an Impression]], [[Actions/Request (Player Core)|Request]], or [[Rules/Skills/Industry|Subsist]]. You can use Fabricated Connections to Make an Impression or Request once per day, and you can also use it once per week to Earn Income or Subsist.
