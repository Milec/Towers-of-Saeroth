# Palatine Enchantment  *Feat 6*

You have found yourself facing supernatural beings often and have learned how to combat them. Whenever you [[Actions/Devise a Stratagem (Player Core 2)|Devise a Stratagem]] against a creature about which you could Recall Knowledge using [[Rules/Skills/Occultism (Player Core)|Occultism]] or [[Rules/Skills/Religion (Player Core)|Religion]], you can make the subsequent [[Actions/Strike (Player Core)|Strike]] against that creature as if the weapon has either a [[Equipment/Ghost Touch (GM Core)|ghost touch]] or [[Equipment/Vitalizing|vitalizing]] property rune.
