# Add Element  *Feat 10*

**Traits** [[Traits/Archetype]]

**Source** [[Sources/Rage of Elements]] pg. 57

**Archetype** [[Archetypes/Kineticist]]

**Prerequisites**
[[Feats/Advanced Element Control]]

---

Choose a second kinetic element to add to the one you already have. You gain an [[Rules/Category Pages/Feats|impulse feat]] for that element. For the purpose of meeting its prerequisites, your kineticist level is equal to half your level. If you gain more kineticist feats, you can select hybrid impulses that have both your elements, as normal for a kineticist.
