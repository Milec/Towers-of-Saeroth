# Furious Sprint two actions or three actions  *Feat 10*

**Traits** [[Traits/Barbarian (Player Core 2)|Barbarian]], [[Traits/Rage (Player Core 2)|Rage]]

**Source** [[Sources/Player Core 2]] pg. 81

---

You rush forward. Stride up to five times, or up to eight times if you used 3 actions. All this movement must be in a straight line (though the GM might allow reasonable variance). You can replace any of these Strides with a [[Actions/Balance (Player Core)|Balance]] action if you need to, which you attempt using an [[Rules/Sidebars/Multiple Attacks with Athletics (Player Core)|Athletics]] check instead of an [[Rules/Skills/Acrobatics (Player Core)|Acrobatics]] check, using the same DC.
