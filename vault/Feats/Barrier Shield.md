# Barrier Shield  *Feat 4*

**Traits** [[Traits/Archetype]]

**Source** [[Sources/Grand Bazaar]] pg. 122

**Archetype** [[Rules/Sidebars/The Fruits of Research|Spell Trickster]]

**Prerequisites**
[[Feats/Spell Trickster Dedication]]; ability to cast [[Spells/Shield|_shield_]]

---

When you cast _shield_, you can modify the spell to create a solid barrier you can use for cover, but not for blocking. You can't use the [[Feats/Shield Block]] reaction when the spell is modified in this way, but you (and only you) can spend an action to [[Actions/Take Cover]] to gain standard cover from it.
