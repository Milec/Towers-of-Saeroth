# Call Bonded Item single action  *Feat 4*

**Traits** [[Traits/Concentrate]], [[Traits/Conjuration]], [[Traits/Teleportation]], [[Traits/Wizard]]

**Prerequisites**
[[Classes/Class Features/Ancestry and Background (class-feature-282)|arcane bond]]
