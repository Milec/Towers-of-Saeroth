# Reptile Speaker  *Feat 1*

**Traits** [[Traits/Lizardfolk (Player Core 2)|Lizardfolk]]

**Source** [[Sources/Player Core 2]] pg. 26

You hear the sounds of reptiles as language. You can ask questions of, receive answers from, and use the [[Rules/Skills/Diplomacy (Player Core)|Diplomacy]] skill with [[Traits/Animal (Player Core)|animals]] that are reptiles (the GM determines which animals count as reptiles).
