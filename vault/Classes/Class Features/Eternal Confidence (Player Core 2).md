# Eternal Confidence  *Class Feature 19*

**Source** [[Sources/Player Core 2]] pg. 158

**Class** Swashbuckler

---

As a swashbuckler at the peak of your skill, you swell with confidence in every attack. Your proficiency rank for your swashbuckler class DC increases to master.

 When you Strike as part of a finisher or Opportune Riposte, you can give the Strike the failure effect from the Confident Finisher action, including the increase from [[Feats/Precise Finisher (Player Core 2)|Precise Finisher]] if you have that feat. You can do so only if the Strike uses a weapon or unarmed attack that you could use for Confident Finisher.
