# Surprise Attack  *Class Feature 1*

**Source** [[Sources/Player Core]] pg. 164

**Class** Rogue

---

You spring into combat faster than foes can react. On the first round of combat, if you roll [[Rules/Skills/Deception]] or [[Rules/Sidebars/Being Stealthy|Stealth]] for initiative, creatures that haven't acted are [[Rules/Conditions/Off-Guard|off-guard]] to you.
