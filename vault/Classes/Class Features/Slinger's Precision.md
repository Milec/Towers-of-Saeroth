# Slinger's Precision  *Class Feature 1*

**Source** [[Sources/Guns & Gears (Remastered)]] pg. 105

**Class** Gunslinger

---

You have steady precision with guns and crossbows and can use weapons that incorporate them effectively. You deal an extra +2 precision damage with Strikes made using [[Equipment/Weapon Groups/Crossbow|crossbows]] that don't have the [[Traits/Repeating|repeating]] trait, and deal an extra 1d4 precision damage on Strikes with [[Equipment/Weapon Groups/Firearm|firearms]] that don't have the repeating trait.

 If you have gunslinging legend, you instead deal +3 additional precision damage with Strikes using crossbows that aren't repeating, and you deal an additional 1d6 precision damage with non-repeating firearm Strikes.

 If you are using a [[Traits/Combination|combination]] weapon whose ranged form is a firearm or crossbow, you use your proficiency with firearms and crossbows for attacks made with the melee portion of that weapon.
