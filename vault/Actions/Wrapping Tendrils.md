# Wrapping Tendrils single action  *Action*

**Source** [[Sources/Tian Xia Character Guide]] pg. 123

---

The urchinpad makes another tendril [[Actions/Strike (Player Core)|Strike]] against the same target. If this Strike hits, the target is also [[Rules/Conditions/Grabbed (Player Core)|grabbed]], as if the urchinpad had successfully [[Actions/Grapple (Player Core)|Grappled]] the target.
