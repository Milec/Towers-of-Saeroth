# Price  *Rules*

**Source** [[Sources/GM Core]] pg. 222

If an item is available for purchase, a character can typically buy it for the listed Price, and the character uses this Price when they use the [[Actions/Craft (Player Core)|Craft]] activity to make the item. If a character wants to sell an item, they can sell it for half its Price (or full Price, if they made the item for someone else on commission), assuming they’re able to find a buyer. The GM determines whether a buyer is available.
