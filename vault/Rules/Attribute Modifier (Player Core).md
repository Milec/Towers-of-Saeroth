# Attribute Modifier  *Rules*

**Source** [[Sources/Player Core]] pg. 10

Each creature has six attribute modifiers: Strength, Dexterity, Constitution, Intelligence, Wisdom, and Charisma. Each of these numbers represents a creature's raw potential and general training. Attributes are described in full [[Rules/Character Creation (Player Core)|later in this chapter]].
