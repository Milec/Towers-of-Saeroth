# Step 1: Check for Random Event  *Rules*

**Source** [[Sources/Kingmaker Adventure Path]] pg. 539

Attempt a DC 16 flat check. On success, a random kingdom event occurs (see [[Rules/Kingdom Events]]). If no random event occurs, the DC for this check in the next Kingdom turn is reduced by 5. Once an event occurs, the DC resets to 16.
