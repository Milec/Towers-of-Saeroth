# Key Terms  *Sidebar*

**Source** [[Sources/Core Rulebook]] pg. 82

**Parent page** [[Classes/Class Features/Ancestry and Background (Core Rulebook)|Barbarian]]

---

You'll see the following key terms in many barbarian class features.

 **[[Traits/Flourish]]**: Flourish actions are techniques that require too much exertion to perform a large number in a row. You can use only 1 action with the flourish trait per turn.

 **[[Traits/Open]]**: These maneuvers work only as your first salvo on your turn. You can use an open action only if you haven't used an action with the attack or open trait yet this turn.

 **[[Traits/Rage]]**: You must be [[Actions/Rage|raging]] to use abilities with the rage trait, and they end automatically when you stop raging.
