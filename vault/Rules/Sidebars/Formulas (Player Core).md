# Formulas  *Sidebar*

**Source** [[Sources/Player Core]] pg. 237

**Parent page** [[Actions/Craft (Player Core)|Craft]]

---

A written formula for an item helps you create it with less difficulty. This has two functions. First, it reduces the time needed to start [[Rules/Sidebars/Crafting Example|Crafting]] from 2 days to 1, as you have less preparation to do. Second, you can Craft [[Traits/Uncommon|uncommon]] and rarer items if you're able to acquire their formulas. See [[Rules/Formulas (Player Core)|Formulas]] for information on formulas.
