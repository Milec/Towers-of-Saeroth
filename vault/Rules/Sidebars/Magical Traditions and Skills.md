# Magical Traditions and Skills  *Sidebar*

**Source** [[Sources/Core Rulebook]] pg. 238

**Parent page** [[Actions/Identify Magic]]

---

Each magical tradition has a corresponding skill, as shown on the table below. You must have the trained proficiency rank in a skill to use it to Identify Magic or [[Actions/Learn a Spell]]. Something without a specific tradition, such as an item with the [[Traits/Magical|magical]] trait, can be identified using any of these skills.
