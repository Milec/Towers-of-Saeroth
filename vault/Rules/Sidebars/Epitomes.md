# Epitomes  *Sidebar*

**Source** [[Sources/Pathfinder -190- The Choosing|Pathfinder #190: The Choosing]] pg. 72

**Parent page** [[Rules/Epitomes]]

---

As the PCs epitomize more cards, you'll need to track which epitomes manifest in the Harrow Court. One way to do this is to devote a Harrow deck to this task—when a card is epitomized, move it into a separate stack or collection from the rest of the cards. You can also use the map on page 70 of this volume, which includes spaces for the PCs track this information as they build the realm up with additional epitomes.
