# Key Terms  *Sidebar*

**Source** [[Sources/Player Core 2]] pg. 70

**Parent page** [[Classes/Class Features/Ancestry and Background (class-feature-841)|Barbarian]]

---

You'll see the following key terms in many barbarian class features.

 **[[Traits/Flourish (Player Core)|Flourish]]:** Actions with the flourish trait are special techniques that require too much exertion for you to perform frequently. You can use only one action with the flourish trait per round.

 **[[Traits/Rage (Player Core 2)|Rage]]:** You must be raging to use abilities with the rage trait, and they end automatically when you stop raging.
