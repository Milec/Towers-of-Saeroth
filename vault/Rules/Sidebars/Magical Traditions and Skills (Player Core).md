# Magical Traditions and Skills  *Sidebar*

**Source** [[Sources/Player Core]] pg. 230

**Parent page** [[Rules/Sidebars/Magical Traditions and Skills (Player Core)|Identify Magic]]

---

Each magical tradition has a corresponding skill, as shown on the table below. You must have the trained proficiency rank in a skill to use it to [[Actions/Identify Magic]] or [[Actions/Learn a Spell]]. Something without a specific tradition, such as an item with the [[Traits/Magical|magical]] trait, can be identified using any of these skills.

## Magical Traditions and Skills

| **Magical Tradition** | **Corresponding Skill** |
| --- | --- |
| Arcane | Arcana |
| Divine | Religion |
| Occult | Occultism |
| Primal | Nature |
