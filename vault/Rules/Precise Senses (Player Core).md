# Precise Senses  *Rules*

**Source** [[Sources/Player Core]] pg. 433

Average vision is a precise sense—a sense that can be used to perceive the world in nuanced detail. The only way to target a creature without having drawbacks is to use a precise sense. You can usually detect a creature automatically with a precise sense unless that creature is [[Actions/Hide (Player Core)|hiding]] or obscured by the environment, in which case you can use the [[Actions/Seek (Player Core)|Seek]] basic action to better detect the creature.
