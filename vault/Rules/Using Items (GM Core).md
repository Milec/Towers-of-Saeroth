# Using Items  *Rules*

**Source** [[Sources/GM Core]] pg. 219

This section presents the rules for how characters use alchemical items, magic items, and other special items during play. Some items function automatically, while others need to be activated. While you need only swing a _[[Equipment/Flaming (GM Core)|flaming]] [[Equipment/Weapons/Greataxe (Player Core)|greataxe]]_ to scorch foes, you need to invest a _[[Equipment/Crown of Intellect|crown of intellect]]_ for it to work, imbibe an [elixir of life](https://2e.aonprd.com/Equipment.aspx?ID=2887) to heal yourself, activate _[[Equipment/Clawed Bracers|clawed bracers]]_ to climb up a wall, and [[Actions/Cast a Spell (Player Core)|Cast a Spell]] using a magical scroll.
