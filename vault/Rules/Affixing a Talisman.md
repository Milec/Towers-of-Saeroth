# Affixing a Talisman  *Rules*

**Source** [[Sources/Core Rulebook]] pg. 565

Each talisman’s stat block indicates the type of item it can be affixed to. Affixing or removing requires using the [Affix a Talisman](https://2e.aonprd.com/Activities.aspx?ID=10) activity. A single talisman can be affixed to only one item at a time, and an item can have only one talisman affixed to it at a time.
