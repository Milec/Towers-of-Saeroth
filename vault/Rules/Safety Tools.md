# Safety Tools  *Rules*

**Source** [[Sources/Gamemastery Guide]] pg. 31

Introducing and using safety tools at your table can help head off some problematic behaviors. The [[Rules/Themes|X-Card and Lines and Veils tools]] allow anyone who feels uncomfortable or unsafe to express their discomfort, with clear guidance on how the rest of the table should respond. This clarity sets obvious boundaries to help enforce the social rules of the table.
