# Skeleton Adjustments  *Rules*

**Source** [[Sources/Book of the Dead]] pg. 73

Most [[Bestiary/Families/Skeleton|skeletons]] are mindless and follow either the basic instincts they had in life or orders given by their creator.

- Add the [[Traits/Skeleton|skeleton]] and [[Traits/Undead|undead]] traits and, optionally, the [[Traits/Mindless|mindless]] trait.
- Add the [[Setting/Languages/Necril]] language if it isn't mindless.
- Decrease the creature's HP based on its level.
- Add the following immunities: [[Traits/Death|death]] effects, [[Traits/Disease|disease]], [[Rules/Conditions/Paralyzed|paralyzed]], [[Traits/Poison|poison]], [[Rules/Conditions/Unconscious|unconscious]]. If it's mindless, add [[Traits/Mental|mental]] as well.
- Add the following resistances with a value based on the creature's level: [[Traits/Cold|cold]], [[Traits/Electricity|electricity]], [[Traits/Fire|fire]], piercing, slashing.
- Add the following abilities. **[[Bestiary/Abilities/Darkvision]]** **[[Bestiary/Abilities/Negative Healing]]**
