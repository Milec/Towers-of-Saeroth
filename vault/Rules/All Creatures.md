# All Creatures  *Rules*

**Source** [[Sources/Character Guide]] pg. 116

This entry applies to all creatures that have the theme template applied, regardless of level. For example, if a template states to add the [[Traits/Lawful|lawful]] trait and remove the [[Traits/Chaotic|chaotic]] trait, that would alter a creature's alignment from chaotic evil to lawful evil.
