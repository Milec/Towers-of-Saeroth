# Set Relics  *Rules*

**Source** [[Sources/Treasure Vault (Remastered)]] pg. 200

Some permanent magic items are strongly attuned to one another, forming a [[Rules/Relics|relic seed]] called a set relic or item set. Such items fit a theme, empowering a specific type of character. A set relic grants gifts and benefits based on its items working and growing more powerful in concert.
