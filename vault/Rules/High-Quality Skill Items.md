# High-Quality Skill Items  *Rules*

**Source** [[Sources/Gamemastery Guide]] pg. 197

Items with skill or Perception bonuses don’t have fundamental runes. If an existing skill bonus item costs less than the listed Price for a high-quality skill item or has a lower level, it likely has a feature such as a limitation, so adjust accordingly. A character in a game with this variant can [[Actions/Craft]] or buy a non-magical item to boost Perception or a skill using the table below.

## Table 4-16: High-Quality Skill Item

| **Quality** | **Item Bonus** | **Item Level** | **Price** |
| --- | --- | --- | --- |
| Expert | +1 | 3 | 40 gp |
| Master | +2 | 9 | 550 gp |
| Legendary | +3 | 17 | 11,000 gp |
