# Low-Light Vision  *Rules*

**Source** [[Sources/Player Core]] pg. 433

A creature with low-light vision can see in [[Rules/Dim Light (Player Core)|dim light]] as though it were [[Rules/Bright Light (Player Core)|bright light]], so it ignores the [[Rules/Conditions/Concealed (Player Core)|concealed]] condition due to dim light.
