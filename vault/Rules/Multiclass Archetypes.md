# Multiclass Archetypes  *Rules*

**Source** [[Sources/Core Rulebook]] pg. 219

Archetypes with the multiclass trait represent diversifying your training into another class’s specialties. You can’t select a multiclass archetype’s dedication feat if you are a member of the class of the same name (for instance, a fighter can’t select the [[Feats/Fighter Dedication]] feat).
