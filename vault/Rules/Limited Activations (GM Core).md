# Limited Activations  *Rules*

**Source** [[Sources/GM Core]] pg. 220

Some items can be activated only a limited number of times per day, as described in the item’s entry. This limit is independent of any costs for activating the item. The limit resets during your [[Rules/Daily Preparations (GM Core)|daily preparations]]. The limit is inherent to the item, so if an ability that can be used only once per day is used, it doesn’t refresh if another creature later invests or tries to activate the item.
