# Specialized Armies  *Rules*

**Source** [[Sources/Kingmaker Adventure Path]] pg. 571

To recruit a specialized army, you must first [[Actions/Send Diplomatic Envoy|establish diplomatic relations]] with the associated group, after which you can attempt the [[Actions/Recruit Army]] activity using a [[Rules/Skills/Statecraft]] check. Only one specialized army can be recruited from each group. The level listed for each army indicates the minimum kingdom level at which the army can be recruited.

 **DC and Modifier Adjustments**: As with basic armies, specialized armies immediately adjust upward in level to match the level of the PCs' kingdom, but unlike basic armies, the DCs and checks for specialized armies have different baselines. In stat blocks for specialized armies, the DCs and modifiers are given for that army at its minimum level, followed by an adjustment value in parenthesis. When the PCs recruit a specialized army at a level above its minimum, calculate its DCs and modifiers by starting with the values for a basic army of that level from the [[Rules/Basic Armies by Level|Basic Armies table]] then applying the adjustment values given here.

 **Darkvision**: Many of the specialized armies presented on the following pages possess the [[Subsystems/Warfare Tactics/Darkvision]] tactic—they gain this tactic for free, and it does not count against the maximum tactics they can possess.

 **Unique Tactics**: Specialized armies possess at least one unique tactic. These tactics count against the maximum tactics the army can know, and these unique tactics cannot be replaced.
