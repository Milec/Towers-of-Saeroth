# Hardness  *Rules*

**Source** [[Sources/Player Core]] pg. 274

Whenever a shield takes damage, the amount of damage it takes is reduced by this amount. This number is particularly relevant for shields because of the [[Feats/Shield Block (Player Core)|Shield Block]] feat . The rules for Hardness appear [[Rules/Item Damage (Player Core)|here]].
