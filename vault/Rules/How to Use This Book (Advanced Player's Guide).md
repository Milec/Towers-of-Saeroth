# How to Use This Book  *Rules*

**Source** [[Sources/Advanced Player's Guide]] pg. 4

The options in this book expand upon the rules contained in the _Core Rulebook_, and that book is required to use the Pathfinder _Advanced Player's Guide_. Some rules of this book indicate other material found in this book with page references. Other products referencing the rules in this book may do so using the superscript citation “APG.”
