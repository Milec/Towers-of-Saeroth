# Shield Statistics  *Rules*

**Source** [[Sources/Player Core]] pg. 274

Shields have statistics that follow the same rules as armor: Price, Speed Penalty, and Bulk. See [[Rules/Armor (Player Core)|armor]] for the rules for those statistics. Their other statistics are described here.
