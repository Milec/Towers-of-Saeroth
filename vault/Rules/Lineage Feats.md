# Lineage Feats  *Rules*

**Source** [[Sources/Advanced Player's Guide]] pg. 28

Some ancestry feats within a versatile heritage have the lineage trait. These feats specify a physiological lineage your character has—such as the type of [[Bestiary/Families/Hag|hag]] that birthed a changeling character, or the type of fiend that influenced a tiefling's birth. You can have only one lineage feat; you can select such a feat only at 1st level, and you can't retrain into or out of this feat.
