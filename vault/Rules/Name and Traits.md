# Name and Traits  *Rules*

**Source** [[Sources/Core Rulebook]] pg. 457

The affliction’s name is given first, followed by its traits in parentheses—including the trait for the type of affliction ([[Traits/Curse|curse]], [[Traits/Disease|disease]], [[Traits/Poison|poison]], and so forth). If the affliction needs to have a level specified, it follows the parentheses, followed by any unusual details, such as restrictions on removing the conditions imposed by an affliction.
