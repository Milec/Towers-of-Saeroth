# Hardness  *Rules*

**Source** [[Sources/Core Rulebook]] pg. 277

Whenever a shield takes damage, the amount of damage it takes is reduced by this amount. This number is particularly relevant for shields because of the [[Feats/Shield Block]] feat. The rules for Hardness appear in [[Rules/Item Damage]].
