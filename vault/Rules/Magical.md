# Magical  *Rules*

**Source** [[Sources/Gamemastery Guide]] pg. 174

Magically propelled vehicles are powered by spells, magic items, or an entirely magical engine. A magical propulsion system can be targeted with counteracting effects like [[Spells/Detect Magic|_dispel magic_]], using the vehicle’s level and a standard DC for that level for the counteract check. A creature can use Arcana, Nature, Occultism, or Religion (depending on the type of magic) for a magical vehicle’s piloting checks.
