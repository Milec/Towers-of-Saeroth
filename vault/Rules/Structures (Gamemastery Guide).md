# Structures  *Rules*

**Source** [[Sources/Gamemastery Guide]] pg. 84

Structures are evocative and make great tertiary items, quirky but not part of a combat build. This allows you to price them affordably, but make sure there isn’t some hidden abuse where the structure drastically alters encounters. The [[Traits/Structure|structure]] trait is intended to help as a starting point.
