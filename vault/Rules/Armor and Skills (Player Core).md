# Armor and Skills  *Rules*

**Source** [[Sources/Player Core]] pg. 226

Some armor imposes a penalty on specific skill checks and DCs. If a creature is wearing armor that imparts a skill penalty, that penalty is applied to the creature’s Strength- and Dexterity-based skill checks and skill DCs, unless the action has the attack trait. Check penalties from armor are detailed [[Rules/Check Penalty (Player Core)|here]].
