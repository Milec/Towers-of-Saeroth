# Name and Traits  *Rules*

**Source** [[Sources/Player Core]] pg. 430

The affliction’s name is given first, followed by its traits in parentheses—including the trait for the type of affliction ([[Traits/Curse (Player Core)|curse]], [[Traits/Disease (Player Core)|disease]], [[Traits/Poison (Player Core)|poison]], and so forth). If the affliction needs to have a level specified, it follows the parentheses, followed by any unusual details, such as restrictions on removing the conditions imposed by an affliction. If no level is listed, the affliction matches the level of the creature, hazard, or item causing the affliction.
