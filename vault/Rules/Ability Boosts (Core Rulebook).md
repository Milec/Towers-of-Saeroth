# Ability Boosts  *Rules*

**Source** [[Sources/Core Rulebook]] pg. 33

This lists the ability scores you apply ability boosts to when creating a character of this ancestry. Most ancestries provide ability boosts to two specified ability scores, plus a free ability boost that you can apply to any other score of your choice. For more about ability boosts, see [[Rules/Ability Boosts|here]].
