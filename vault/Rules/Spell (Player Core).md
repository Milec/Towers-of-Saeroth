# Spell  *Rules*

**Source** [[Sources/Player Core]] pg. 11

Spells are magical effects created by performing mystical incantations and gestures known only to those with special training or inborn abilities. Casting a spell is an activity that usually uses 2 actions. Each spell specifies what it targets, the actions needed to cast it, its effects, and how it can be resisted. If a class grants spells, the basics of that ability are provided in the class description in [[Rules/Chapter 3- Classes (rules-2098)|Chapter 3]], while the spells themselves are detailed in [[Rules/Chapter 7- Spells (rules-2221)|Chapter 7]].

 Spells have ranks ranging from 1st to 10th, which measure their power; characters and monsters can usually cast only a certain number of spells of any given rank.
