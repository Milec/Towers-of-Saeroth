# Sailing Lore in Naval Chases  *Rules*

**Source** [[Sources/High Seas]] pg. 37

Since it’s a catch-all skill for many different shipboard tasks, the [[Rules/Sidebars/Common Lore Subcategories (Player Core)|Sailing Lore]] skill can often be used in place of other skills during a naval chase. If a character is highly skilled in Sailing Lore, this is their time to shine! Allow liberal substitutions if you have a player who’s highly invested in the skill. [[Rules/Skills/Nature (Player Core)|Nature]] can be used instead of Sailing Lore for wind-powered vehicles, but only for Sailing Lore tasks related to actually steering the ship, not for other shipboard tasks.
