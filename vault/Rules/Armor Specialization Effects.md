# Armor Specialization Effects  *Rules*

**Source** [[Sources/Core Rulebook]] pg. 275

Certain class features can grant you additional benefits with certain armors. This is called an armor specialization effect. The exact effect depends on which armor group your armor belongs to, as listed below. Only medium and heavy armors have armor specialization effects. See [here](ArmorGroups.aspx) for details on each armor specialization effect.
