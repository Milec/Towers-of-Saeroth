# Affixing a Talisman  *Rules*

**Source** [[Sources/GM Core]] pg. 263

Each talisman’s stat block indicates the type of item it can be affixed to. Affixing or removing a talisman requires using the [[Actions/Affix a Talisman (GM Core)|Affix a Talisman]] activity. A single talisman can be affixed to only one item at a time, and an item can have only one talisman affixed to it at a time without suppressing them all.
