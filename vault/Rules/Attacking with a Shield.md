# Attacking with a Shield  *Rules*

**Source** [[Sources/Core Rulebook]] pg. 277

A shield can be used as a martial weapon for attacks, using the statistics listed for a [[Equipment/Weapons/Shield Bash (Player Core)|shield bash]]. The shield bash is an option only for shields that weren't designed to be used as weapons. A shield can't have runes added to it. You can also buy and attach a [[Equipment/Weapons/Shield Boss (Player Core)|shield boss]] or [[Equipment/Weapons/Shield Spikes (Player Core)|shield spikes]] to a shield to make it a more practical weapon. These work like other weapons and can even be etched with runes.
