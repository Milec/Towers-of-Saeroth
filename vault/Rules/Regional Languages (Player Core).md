# Regional Languages  *Rules*

**Source** [[Sources/Player Core]] pg. 34

These regional languages are uncommon outside the region of their genesis. A character hailing from one of the regions listed below automatically has access to that language. In the Inner Sea region, the language referred to as Common elsewhere in the rules is the same as Taldane.

## Table 2-3: Regional Language

| **Language** | **Speakers** |
| --- | --- |
| Hallit | Broken Lands, Eye of Dread, Saga Lands |
| Kelish | Golden Road |
| Mwangi | Mwangi Expanse, the Shackles, Thuvia, Vidrian |
| Osiriani | Geb, Katapesh, Mana Wastes, Nex, Osirion, Rahadoum, Thuvia |
| Shoanti | Hold of Belkzen, Varisia |
| Skald | Irrisen, Lands of the Linnorm Kings |
| Tien | Lands of the Linnorm Kings, Realm of the Mammoth Lords, Tian Xia |
| Varisian | Brevoy, the Gravelands, Nidal, Nirmathas, Ustalav, Varisia |
| Vudrani | Jalmeray, Katapesh, Nex, Vudra |
