# Condition  *Rules*

**Source** [[Sources/Player Core]] pg. 10

An ongoing effect that changes how a character can act, or that alters some of their statistics, is called a condition. The rules for the basic conditions used in the game can be found in the [[Rules/Conditions Appendix]] at the back of this book.
