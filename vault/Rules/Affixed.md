# Affixed  *Rules*

**Source** [[Sources/GM Core]] pg. 222

Talismans function only if affixed to other items. They have a Usage entry indicating the type or types of items to which a character can attach them, such as “affixed to armor.” Rules for affixing a talisman are [[Rules/Affixing a Talisman (GM Core)|here]].
