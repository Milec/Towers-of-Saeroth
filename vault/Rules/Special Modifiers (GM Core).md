# Special Modifiers  *Rules*

**Source** [[Sources/GM Core]] pg. 116

You can also add special, thematic modifiers for certain skill uses. For instance, you might give a creature that secretes adhesive “[[Rules/Sidebars/Multiple Attacks with Athletics (Player Core)|Athletics]] +7 (+9 to [[Actions/Climb (Player Core)|Climb]] or [[Bestiary/Abilities/Grab (Rage of Elements)|Grab]]).” This special bonus should still remain at or below the extreme number, especially if it has a combat purpose like the Grab bonus above.
