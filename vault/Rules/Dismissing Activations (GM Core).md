# Dismissing Activations  *Rules*

**Source** [[Sources/GM Core]] pg. 221

Some item effects can be dismissed, ending the duration early due to you or the target taking action. Dismissing an activation requires using the [[Actions/Dismiss (Player Core)|Dismiss]] action.
