# Using True Names  *Rules*

**Source** [[Sources/Secrets of Magic]] pg. 245

Certain spells, feats, and items have the true name trait. This trait means they require you to know a creature's true name to use them. But even without these specialized abilities, knowing a creature's true name gives you certain advantages. If you know a creature's true name, you have a +2 circumstance bonus to the following checks.

- Checks to [[Actions/Recall Knowledge]] about the creature
- [[Rules/Skills/Arcana]], [[Magic/Domains/Nature]], [[Rules/Skills/Occultism]], or [[Rules/Skills/Religion]] checks relating to the creature, such as [[Actions/Decipher Writing|Deciphering its Writing]], [[Actions/Identify Magic|Identifying its Magic]], or [[Actions/Learn a Spell|Learning its Spells]]
- [[Rules/Skills/Deception]], [[Rules/Sidebars/Changing Attitudes|Diplomacy]], and [[Rules/Skills/Intimidation]] checks used on or related to the creature, such as to [[Actions/Coerce]] it, [[Actions/Gather Information]] on it, or [[Actions/Impersonate]] it
