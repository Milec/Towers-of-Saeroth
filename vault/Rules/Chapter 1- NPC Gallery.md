# Chapter 1: NPC Gallery  *Rules*

**Source** [[Sources/NPC Core]] pg. 7

In this chapter, you'll find all kinds of NPCs across a variety of categories and roles. Each section includes stat blocks that fit a theme, sidebars with extra details, and a section of tidbits a GM can drop into a game using these NPCs. If you need to find an NPC by level, use the [search feature](Search.aspx?q=type%3Acreature+source%3A) and filter by the level range you need.

 Because [[Ancestries/Human|humans]] make up the majority of the population in most areas of Golarion, the stat blocks in this chapter are all humans. If you want to change the ancestry of a stat block, use the ancestry adjustments found [here](MonsterTemplates.aspx)!
