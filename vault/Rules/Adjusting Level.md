# Adjusting Level  *Rules*

**Source** [[Sources/Gamemastery Guide]] pg. 203

Sometimes you'll need an NPC that fills a particular role—say an angry drunk— but the level in the stat block presented isn't the right fit for your group. You can start by applying the [[Rules/Elite Adjustment|elite]] or [[Rules/Weak Adjustments|weak]] adjustments to adjust the NPC's level by 1 in either direction.

 If you need to change the NPC's level beyond that, use the values from the tables in [[Rules/Building Creatures]], and add or remove special abilities as necessary to suit the NPC's new level.
