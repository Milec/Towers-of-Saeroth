# Specialty Basic Actions  *Category Page*

**Source** [[Sources/Player Core]] pg. 418

These actions are useful under specific circumstances. The [[Actions/Arrest a Fall]], [[Actions/Burrow]], and [[Actions/Fly]] actions require you to have a special movement type. The climb and swim Speeds use the corresponding actions from the [[Rules/Sidebars/Falling|Athletics]] skill.
