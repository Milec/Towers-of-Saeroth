# Constant and Automatic Abilities  *Rules*

**Source** [[Sources/GM Core]] pg. 125

Certain abilities shouldn't use any actions. [[Bestiary/Abilities/Aura|Auras]] are a common constant ability, with [[Bestiary/Abilities/Frightful Presence|frightful presence]], the [[Bestiary/Cinder Rat|cinder rat]]'s fetid fumes, and the [[Bestiary/Families/Xulgath|xulgath]]'s stench as notable examples. An aura needs a range, and if it needs a DC, you'll usually set it to the moderate spell DC unless the aura is one of the creature's defining concepts. For example, the xulgath's stench DC is significantly higher because the aura is such an iconic part of the creature.

Abilities the creature has no control over should be automatic. For example, the [[Bestiary/Living Wildfire|living wildfire]] fire elemental explodes into flames when it dies. It has no option not to, so this wouldn't make sense as a reaction or free action. Conversely, the [[Bestiary/Abilities/Ferocity]] ability is a reaction because it requires the creature to give itself a last push to stay at 1 HP.
