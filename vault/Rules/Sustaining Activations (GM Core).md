# Sustaining Activations  *Rules*

**Source** [[Sources/GM Core]] pg. 220

Some items, once activated, have effects that can be sustained if you concentrate on them. Sustaining an effect requires using the [[Actions/Sustain]] action. If an item’s description states that you can sustain the effect, that effect lasts until the end of your turn in the round after you Activated the Item. You can use a Sustain action on that turn to extend the duration.
