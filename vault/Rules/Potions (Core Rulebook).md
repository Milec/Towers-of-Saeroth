# Potions  *Rules*

**Source** [[Sources/Core Rulebook]] pg. 562

A potion is a magical liquid activated when you drink it, which uses it up. Potions have the [[Traits/Potion|potion]] trait. You can activate a potion with an Interact action as you drink it or feed it to another creature. You can feed a potion only to a creature that is within reach and willing or otherwise so helpless that it can’t resist. You usually need only one hand to consume a potion or feed it to another creature.
