# High-Quality  *Rules*

**Source** [[Sources/Gamemastery Guide]] pg. 197

In this variant, gear can provide bonuses even if it’s not magical. This is useful for games and settings that set out to give fine, non-magical items the same prominence as magic items. High-quality gear requires the corresponding proficiency rank in [[Rules/Sidebars/Crafting Example|Crafting]] to [[Actions/Craft]].
