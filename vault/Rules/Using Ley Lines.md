# Using Ley Lines  *Rules*

**Source** [[Sources/Secrets of Magic]] pg. 215

While locating a ley line might be a difficult process, making use of a ley line's power is remarkably simple. Accessing the power of a ley line requires using the [[Rules/Skills/Intimidation|Tap Ley Line]] general skill action. The results of this action are based on the benefits and drawbacks of a ley line.
