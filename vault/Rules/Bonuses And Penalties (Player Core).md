# Bonuses And Penalties  *Rules*

**Source** [[Sources/Player Core]] pg. 10

[[Rules/Bonuses (Player Core)|Bonuses]] and [[Rules/Penalties|penalties]] apply to checks and certain statistics. There are several types of bonuses and penalties. If you have more than one bonus of the same type, you use only the highest bonus. Likewise, you use only the worst penalty of each type.
