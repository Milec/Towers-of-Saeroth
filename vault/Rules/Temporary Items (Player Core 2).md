# Temporary Items  *Rules*

**Source** [[Sources/Player Core 2]] pg. 174

Several archetypes allow you to prepare temporary items. Much like the [[Traits/Infused (Player Core 2)|infused]] items created by [[Classes/Class Features/Ancestry and Background (Player Core 2)|alchemists]], these temporary items last only a short time before becoming useless. Examples include temporary scrolls created by the [[Archetypes/Scroll Trickster (Player Core 2)|scroll trickster]] and temporary weapons, armor, or adventuring gear created by the [[Archetypes/Scrounger (Player Core 2)|scrounger]].

Temporary items are clearly not up to the same quality as other items, so they typically can’t be sold. If an ability doesn’t list how long a temporary item lasts, the item lasts until the next time you make your [[Rules/Daily Preparations (GM Core)|daily preparations]]. Any effect created by a temporary item also ends at that time if it hasn’t already (unless it’s a permanent effect).
