# Basic Magic Armor  *Rules*

**Source** [[Sources/GM Core]] pg. 229

The most common special armors are suits of armor with some combination of _[[Equipment/Armor Potency (GM Core)|armor potency]]_ and _[[Equipment/Resilient (GM Core)|resilient runes]]_. The [[Equipment/Magic Armor (GM Core)|magic armor]] stat block provides a quick reference for these types of armor.
