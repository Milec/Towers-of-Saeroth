# Armor Class (AC)  *Rules*

**Source** [[Sources/Player Core]] pg. 10

All creatures in the game have an [[Rules/Armor Class (rules-2295)|Armor Class]]. This score represents how hard it is to hit and damage a creature. It serves as the Difficulty Class for hitting a creature with an attack.
