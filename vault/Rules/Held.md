# Held  *Rules*

**Source** [[Sources/GM Core]] pg. 222

If a character must wield the item to use it, this entry in the item’s stat block lists the word “held” along with the number of hands the character must use when wielding the item, such as “held in 1 hand.” The rules for carrying and using items are provided [[Rules/Carrying Items|here]].
