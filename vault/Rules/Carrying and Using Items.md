# Carrying and Using Items  *Rules*

**Source** [[Sources/Core Rulebook]] pg. 271

A character carries items in three ways: held, worn, and stowed. Held items are in your hands; a character typically has two hands, allowing them to hold an item in each hand or a single two-handed item using both hands. Worn items are tucked into pockets, belt pouches, bandoliers, weapon sheaths, and so forth, and they can be retrieved and returned relatively quickly. Stowed items are in a [[Equipment/Backpack|backpack]] or a similar container, and they are more difficult to access.

 Drawing a worn item or changing how you're carrying an item usually requires you to use an Interact action (though to drop an item, you use the [[Actions/Release]] action instead). [[Rules/Wielding Items|Table 6–2: Changing Equipment]] lists some ways that you might change the items you're holding or carrying, and the number of hands you need to do so.

 Many ways of using items require you to spend multiple actions. For example, drinking a potion worn at your belt requires using an Interact action to draw it and then using a second action to drink it as described in its Activate entry.
