# Character Advancement  *Rules*

**Source** [[Sources/Gamemastery Guide]] pg. 193

A dual-class character gains the class feats and class features for both classes at each level as they advance, with the exception of ability boosts, general feats, skill feats, and skill increases—the character gets each of these benefits only once per level, since both classes would provide the same benefit. (A dual-class [[Classes/Class Features/Ancestry and Background (class-feature-232)|rogue]]/[[Classes/Class Features/Ancestry and Background (class-feature-204)|ranger]] still gets the extra skill feat and skill increase at levels where the other class doesn’t provide them.)

 If a character gains the same proficiency rank in a statistic more than once, they still use only the highest rank. In the example above, when the [[Classes/Class Features/Ancestry and Background (class-feature-111)|cleric]] gets Alertness at 5th level, they wouldn’t change their Perception rank, since it was already expert due to the ranger’s initial proficiencies.
