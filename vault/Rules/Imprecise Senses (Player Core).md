# Imprecise Senses  *Rules*

**Source** [[Sources/Player Core]] pg. 433

Average hearing is an imprecise sense—it can’t detect the full range of detail that a precise sense can. You can usually sense a creature automatically with an imprecise sense, but it has the [[Rules/Conditions/Hidden (Player Core)|hidden]] condition instead of the [[Rules/Conditions/Observed (Player Core)|observed]] condition. It might be [[Rules/Undetected (Player Core)|undetected]] by you if it’s using [[Rules/Sidebars/Being Stealthy (Player Core)|Stealth]] or is in an environment that distorts the sense, such as a noisy room in the case of hearing. In those cases, you have to use the [[Actions/Seek (Player Core)|Seek]] basic action to detect the creature. At best, an imprecise sense can be used to make an undetected creature (or one you didn’t even know was there) merely hidden—it can’t make the creature observed.
