# Counteracting a Magical Hazard  *Rules*

**Source** [[Sources/Core Rulebook]] pg. 521

Some magical hazards can be [[Rules/Counteracting (Core Rulebook)|counteracted]] using [[Spells/Dispel Magic|_dispel magic_]]. These hazards’ spell levels and counteract DCs are listed in their stat block. Counteracting a hazard otherwise works like using a skill check to disable the hazard.
