# Inclines  *Rules*

**Source** [[Sources/Player Core]] pg. 423

An incline is an area so steep that you need to [[Actions/Climb (Player Core)|Climb]] using the [[Rules/Sidebars/Multiple Attacks with Athletics (Player Core)|Athletics]] skill in order to progress upward. You’re [[Rules/Conditions/Off-Guard|off-guard]] when Climbing an incline.
