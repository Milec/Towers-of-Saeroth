# Class  *Rules*

**Source** [[Sources/Player Core]] pg. 10

A class represents the adventuring profession chosen by a character. A character's class determines most of their proficiencies, grants the character Hit Points each time they gain a new level, and gives access to a set of class feats. Classes appear in [[Rules/Chapter 3- Classes (rules-2098)|Chapter 3]].
