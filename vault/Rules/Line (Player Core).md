# Line  *Rules*

**Source** [[Sources/Player Core]] pg. 428

A line shoots forth from you, following a straight path in a direction of your choosing. The line affects each creature whose space it overlaps. Unless a line effect says otherwise, it is 5 feet wide. For example, the [[Spells/Lightning Bolt (Player Core)|_lightning bolt_]] spell’s area is a 60-foot line that’s 5 feet wide.
