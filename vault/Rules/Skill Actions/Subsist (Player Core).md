# Subsist (Untrained)  *General Skill Action*

**Source** [[Sources/Player Core]] pg. 232

If you need to provide food and shelter, you can use the Subsist downtime activity. This typically uses [[Rules/Sidebars/Examining Forgeries|Society]] if you're in a settlement or [[Rules/Skills/Survival]] if you're in the wild.

## Skill Uses

[[Rules/Skills/Society (Player Core)|[Society]]] Subsist in a settlement by finding shelter, scrounging, or begging for food.

[[Rules/Skills/Survival (Player Core)|[Survival]]] Subsist in the wild by foraging for food and building shelter.
