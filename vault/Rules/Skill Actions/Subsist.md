# Subsist (Untrained)  *General Skill Action*

**Source** [[Sources/Core Rulebook]] pg. 238

If you need to provide food and shelter, you can use the Subsist downtime activity. This typically uses Society if you’re in a settlement or Survival if you’re in the wild.

## Skill Uses

[[Rules/Sidebars/Examining Forgeries|[Society]]] Subsist in a settlement by finding shelter, scrounging, or begging for food.

[[Rules/Skills/Survival|[Survival]]] Subsist in the wild by foraging for food and building shelter.
